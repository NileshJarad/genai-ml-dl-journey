# ML Interview Questions

## Technical Questions

1. **Linear Regression**: What is the difference between L1 and L2 regularization? When would you choose one over the other?

2. **Decision Trees**: How does a decision tree handle categorical vs. numerical features? What's the maximum depth and why is it important?

3. **Cross-Validation**: Explain k-fold cross-validation. Why is it better than a simple train/test split? What are the common pitfalls?

4. **Overfitting**: How do you detect if a model is overfitting? What techniques can you use to prevent or mitigate it?

5. **Classification Metrics**: When should you use precision vs. recall vs. F1-score? Give an example where one would be more appropriate than another.

6. **Support Vector Machines**: How do you choose the optimal C and gamma in an SVM? What happens when C or gamma is too large/small?

7. **Neural Networks**: How does gradient descent work for training a neural network? What are different activation functions and why choose ReLU?

8. **Dimensionality Reduction**: Compare PCA and t-SNE. When would you use one over the other? What are the trade-offs?

9. **K-Means**: How do you determine the optimal number of clusters (k)? What algorithms can help?

10. **Feature Engineering**: What are some common feature engineering techniques that improve model performance?

11. **Bagging vs Boosting**: What's the fundamental difference between bagging and boosting approaches? What are popular implementations?

12. **Transfer Learning**: How does transfer learning work in deep learning? What are its advantages and limitations?

13. **SMOTE**: What is SMOTE used for? How does it help with imbalanced datasets?

14. **Regularization**: Explain L1, L2, and dropout regularization. How do they work differently?

15. **Early Stopping**: How does early stopping work in neural networks? What callbacks can implement this?

16. **Hyperparameter Tuning**: Compare grid search and random search. When is random search preferable?

17. **Ensemble Methods**: Why do ensembles improve performance? Discuss bagging vs. boosting vs. stacking.

18. **Class Imbalance**: What methods can address class imbalance in machine learning problems?

19. **Softmax**: Explain how softmax functions in classifiers. Why is it preferred over sigmoid for multi-class classification?

20. **Tensors**: What is a tensor? How does tensor computation differ from dense matrix multiplication?

## Data Engineering Questions

21. How do you handle missing values in a dataset? What strategies would you use?

22. What are the differences between normalization and standardization? When would you use each?

23. How do you create meaningful features from raw data?

24. What is the purpose of cross-validation in evaluating ML models?

25. How would you compare two different ML models? What metrics would you use?

## Practical Questions

26. Write a Python code to perform k-fold cross-validation on iris dataset using scikit-learn.

27. Given a confusion matrix, calculate precision, recall, and F1 score step by step.

28. Explain the bias-variance tradeoff with a simple Python implementation.

29. How would you build a pipeline for end-to-end ML from raw data to deployment?

30. What's the difference between training accuracy, validation accuracy, and test accuracy?

34. What role does attention play in LLM architecture?
