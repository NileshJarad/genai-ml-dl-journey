# genai-ml-dl-journey

A comprehensive learning journey through Generative AI, Machine Learning, and Deep Learning.

## Overview

This repository documents my learning path from foundational concepts to advanced applications in AI/ML/DL. It's structured as a progressive journey through:

- **00-roadmap** - Learning roadmap, weekly plans, and progress tracking
- **01-python-for-ai** - Python fundamentals for AI/ML
- **02-math-for-ml** - Mathematics essentials (linear algebra, statistics, probability)
- **03-machine-learning** - Core ML algorithms and techniques
- **04-deep-learning** - Neural networks, CNNs, RNNs, Transformers
- **05-generative-ai** - LLM fundamentals, prompt engineering, RAG, agents, fine-tuning
- **06-mobile-ai** - On-device ML, Core ML, TensorFlow Lite, MediaPipe
- **07-pocs** - Proof of Concept projects
- **08-interview-prep** - Interview questions across domains
- **09-projects** - Project ideas, case studies, and architecture diagrams
- **docs** - Setup guide, coding standards, and resources
